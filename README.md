# NYL strikes
Builds the day's key QQQ strikes every weekday morning on GitHub (free) and shows them at this repo's GitHub Pages site with a Copy button for TradingView. Your PC doesn't need to be on.

Runs: ~6:45 ET (pre-open list) and ~9:40 ET (locked at the open). GitHub can start scheduled runs 5–20 minutes late.
Run now: Actions tab → Build NYL strikes → Run workflow.
